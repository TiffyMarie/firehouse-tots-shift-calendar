+ Add a calendar

Option 1 – Import a .ics file (always works, even offline)

Option 2 – Link a calendar URL (Google "Secret address in iCal format" or Apple public calendar webcal:// link)

Heads up: Google and Apple don't let websites read calendar links directly (a browser safety rule called CORS), so a link usually won't load here on its own. If it fails, use Option 1. In Google Calendar: Settings → Import & export → Export, then unzip and import the .ics. In Apple Calendar on a Mac: File → Export.

Advanced: calendar helper (proxy) URL

Optional. Paste the address of your own calendar helper (for example, a free Cloudflare Worker you or a trusted helper set up). Your private calendar link is sent to this helper, so only use one you control. Never use a random public "CORS proxy". Your secret link would be visible to whoever runs it.

Family calendars stay on this device. They are not included in the share link or calendar export.
